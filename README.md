## Project Description
Customer Feedback Sentiment Analysis is an NLP-based machine learning project designed to analyze customer reviews and classify them into positive, negative, and neutral sentiments. The project helps businesses understand customer opinions, improve services, and gain valuable insights from textual feedback.

---

## Features
- Text preprocessing and cleaning
- Sentiment classification
- NLP-based analysis
- Machine Learning model implementation
- Customer review categorization
- Data visualization and insights

## Run Locally

Clone the repository

```bash
git clone https://github.com/Chopra-14/customer-feedback-sentiment-analysis.git
```

Go to project directory

```bash
cd customer-feedback-sentiment-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```
